# Devlord Travel

A responsive travel-booking website built with HTML, CSS and vanilla JavaScript.

## Files

- `index.html` — website structure
- `style.css` — all styling and responsive layout
- `script.js` — tabs, mobile navigation, date rules, form interaction
- `README.md` — project notes

## How to run

1. Extract the ZIP.
2. Open the `devlord-travel` folder.
3. Double-click `index.html`.
4. For development, open the folder in VS Code and use Live Server.

## Images

The current project uses remote Unsplash images so you can run it immediately while connected to the internet.

To use your own downloaded images:

1. Create an `images` folder.
2. Put your pictures inside it.
3. Change an image like:

```html
<img src="https://..." alt="Dubai">
```

to:

```html
<img src="images/dubai.jpg" alt="Dubai">
```

For the hero background, replace the URL inside `.hero` in `style.css`.
